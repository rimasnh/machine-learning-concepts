# Machine Learning Concepts

A learning series working through core machine learning concepts with hands-on notebooks — each one builds and evaluates a model from scratch on a real dataset.

## Notebooks

| Notebook | What it covers |
|---|---|
| `bias-variance/bias-variance-tradeoff.ipynb` | The bias–variance tradeoff: how model complexity affects training vs. validation error, with visualizations |
| `hospital-readmission-prediction/hospital-readmission-prediction.ipynb` | End-to-end classification: predicting hospital readmission — data prep, feature engineering, model training, and evaluation |

## Tech stack

Python · Jupyter · scikit-learn · pandas · Matplotlib
